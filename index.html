Mahyar Compressor v2.0

برنامه Mahyar Compressor به صورت کامل بسته شد

تمامی پردازش‌های پس‌زمینه، سینی سیستم و هسته FFmpeg با موفقیت متوقف شدند.

فایل‌های ارتقایافته پایتون (با دکمه‌های جدید + رفع ارور dock)

تمام دکمه‌های خلاقانه جدید (مکث/ادامه پردازش Pause/Resume، تغییر تم نئونی ۴گانه، سنجاق روی همه پنجره‌ها Pin، انتخاب نرخ فریم 60/30 FPS، حالت Turbo Boost، افزودن پوشه کامل، حذف انجام‌شده‌ها، کپی گزارش و دکمه‌های پخش/پوشه روی هر کارت) به همراه رفع کامل ارور dock در فایل‌های پایتون زیر اعمال شده‌اند:

src/vidshrink/app.py پنجره اصلی، دکمه‌های جدید (تم، پین، مکث/ادامه، افزودن پوشه، گزارش) + رفع ارور dock
src/vidshrink/widgets.py ویجت‌های نئونی جدید، آیکون‌های تم/پین/مکث و دکمه‌های پخش/پوشه روی هر کارت ویدیو
src/vidshrink/engine.py پشتیبانی واقعی از مکث/ادامه FFmpeg در ویندوز، محدودکننده 60/30 FPS و حالت Turbo
src/vidshrink/i18n.py ترجمه‌های کامل فارسی و انگلیسی برای تمام دکمه‌ها و قابلیت‌های جدید
.github/workflows/build.yml ورک‌فلوی بهینه‌شده GitHub Actions برای تست خودکار و ساخت فایل EXE
tests/test_engine.py تست‌های کامل شامل تست ساخت پنجره، تغییر تم، کپی گزارش و نرخ فریم
Windows PowerShell / CMD — اجرای مستقیم یا ساخت EXE 
pip install -r requirements.txt
python run.py

# برای ساخت فایل تک‌فایلی ویندوز (dist/MahyarCompressor.exe):
python scripts/build.py
