## 🚀 دکمه‌ها و قابلیت‌های خلاقانه جدید در `Mahyar Compressor PRO v2.0`

علاوه بر تغییر نام کامل به **Mahyar Compressor**، حالت **فول‌اسکرین خودکار**، **بک‌گراند حساس به حرکت ماوس** و **رفع کامل ارور `dock`**، دکمه‌ها و ابزارهای حرفه‌ای زیر به هر دو نسخه **دسکتاپ ویندوز (`src/vidshrink/`)** و **استودیوی تحت وب (`index.html`)** اضافه شدند:

### ۱. دکمه‌های جدید نوار فرماندهی بالا (Top Cyber HUD)
- **🎨 دکمه تغییر تم نئونی (`تم نئون / Switch Neon Theme`)**: تغییر آنی رنگ‌بندی ابرهای پلاسمایی و ذرات بک‌گراند بین ۴ تم اختصاصی:
  1. *Cyber Ultraviolet* (بنفش/فیروزه‌ای)
  2. *Matrix Emerald* (سبز زمردی/فیروزه‌ای)
  3. *Crimson Overdrive* (سرخ لیزری/مگنتا)
  4. *Solar Gold* (طلایی خورشیدی/فیروزه‌ای)
- **📌 دکمه سنجاق روی همه پنجره‌ها (`Always on Top Pin`)**: نگه داشتن پنجره برنامه روی تمام برنامه‌های باز ویندوز.
- **🗕 دکمه انتقال سریع به داک پایین (`داک پایین / Mini Dock`)**: جمع کردن برنامه به نوار شناور پایین صفحه.
- **⛶ دکمه تمام‌صفحه (`Fullscreen / F11`)** و **⏻ دکمه خروج کامل (`Full Exit`)**.

### ۲. دکمه‌ها و کنترل‌های جدید پنل فرماندهی (Command Deck)
- **⏸️ / ▶️ دکمه مکث و ادامه پردازش (`مکث موقت / ادامه پردازش — Pause / Resume`)**:
  - هنگام فشرده‌سازی ویدیوهای سنگین، در کنار دکمه توقف ظاهر می‌شود و در ویندوز با استفاده از `NtSuspendProcess` / `NtResumeProcess` پروسه FFmpeg را بدون از دست رفتن پیشرفت فریز و دوباره بیدار می‌کند (`Ctrl + P`).
- **🎞️ انتخابگر نرخ فریم (`نرخ فریم تصویر FPS`: `اصلی` | `60 فریم` | `30 فریم`)**:
  - تبدیل ویدیوهای ۱۲۰ یا ۶۰ فریم موبایل/گیمینگ به ۶۰ یا ۳۰ فریم برای کاهش چشمگیر حجم فایل بدون افت کیفیت رزولوشن.
- **🚀 سوییچ پردازش فوق‌سریع (`Turbo Boost`)**:
  - اختصاص اولویت بالای پردازشی (`ABOVE_NORMAL_PRIORITY_CLASS`) به هسته FFmpeg برای رندرینگ با حداکثر سرعت سیستم.

### ۳. نوار ابزار تاکتیکی صف و دکمه‌های روی هر کارت ویدیو (Tactical Queue Toolbar)
- **📁 دکمه `+ افزودن پوشه` (`Add Folder`)**: انتخاب یک پوشه و اسکن خودکار تمام زیرپوشه‌ها برای افزودن دسته‌جمعی ویدیوها.
- **✅ دکمه `حذف انجام‌شده‌ها` (`Clear Done`)**: پاک کردن ویدیوهای تکمیل‌شده از لیست بدون دست زدن به ویدیوهای در صف انتظار.
- **🔄 دکمه هوشمند `تلاش مجدد ناموفق‌ها` (`Retry Failed`)**: در صورت بروز خطا در هر فایل، خودکار ظاهر می‌شود تا با یک کلیک دوباره پردازش شود.
- **📋 دکمه `کپی گزارش آمار` (`Copy Report`)**: کپی خلاصه کامل تعداد فایل‌ها، حجم اولیه، حجم نهایی و درصد صرفه‌جویی در کلیپ‌بورد.
- **▶️ / 📂 / ✕ دکمه‌های اختصاصی روی هر کارت ویدیو**:
  - دکمه **پخش مستقیم ویدیو (`Play`)**، دکمه **باز کردن پوشه حاوی فایل (`Open Folder`)** و دکمه **حذف از صف (`Remove`)** روی تک‌تک کارت‌ها.

### ۴. دکمه‌های ارتقایافته داک شناور پایین (`MiniDock`) و سینی سیستم (`System Tray`)
- دارای دکمه‌های **`+ افزودن ویدیو`**، **`مکث / ادامه (Pause/Resume)`**، **`شروع / توقف`**، **`پوشه خروجی`**، **`تغییر تم`**، **`بازگشت به نمای کامل (Expand)`** و **`خروج کامل (Full Exit)`**.

## 📦 اجرای برنامه و ساخت فایل `.exe` در ویندوز

```bash
pip install -r requirements-dev.txt
pytest -v                          # اجرای تست‌های کامل (شامل تست پنجره، داک پایین، تم و FPS)
python run.py                      # اجرای مستقیم برنامه در حالت فول‌اسکرین
python scripts/build.py            # ساخت فایل اجرایی تک‌فایلی dist/MahyarCompressor.exe
```
